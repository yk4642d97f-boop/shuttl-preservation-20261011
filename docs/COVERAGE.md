# 保全范围与已知缺口

## 确认纳入的范围

本次在系统数据卷建立了 1,796,736 条文件路径索引，结合文件名、源码/文档引用、6,872 个额外小文本文件的内容搜索，以及源码、媒体、会话三个专项审计确定范围。并不是仅按文件名包含 Shuttl 打包。

完整选中主开发目录、早期 YuXi 原型与历史前端、比赛材料与压缩包、两套宣传制作工程、独立视频别名、AutoDL 本机备份、Shuttl 应用支持目录、五套模拟器应用与数据、相关 Claude/Codex/Cowork 开发会话和附件。额外保存 Shuttl 专用部署密钥、配置、依赖版本、诊断和扫描证据；这些原始资料全部随加密归档保存。

对选中目录没有按 `.gitignore` 或缓存名字过滤：隐藏备份、嵌套 Git、未提交代码、本地虚拟环境、模型、实验缓存、构建结果都纳入。清单保留每个路径，因此内容去重不删除历史版本或文件位置。

盘点结果约 998,104 个条目，其中 825,352 个普通文件、111,575 个符号链接、61,177 个目录；逻辑文件体积 183,837,712,938 字节，按 inode 去重后 153,778,709,488 字节。最终打包数量可能因生成中的审计文件而微调，以归档 create-report 和 manifest 为准。

## 不能声称已经保全的内容

- macOS 返回 326 条访问失败，涉及隐私保护或系统权限目录。完整列表在加密归档的审计目录中。全盘路径索引在超过十分钟没有进展后终止；因此不能将它描述为所有磁盘位置均已成功读取。
- 回收站、部分系统容器等受保护位置未获读取；仅存在 iCloud、其他云端或未挂载设备中的资料不可能由本机扫描证明已下载。
- 历史报告提到的若干 `/tmp/shuttl-device-...` 目录在扫描前已经不存在。还有四条历史 BST 自测软链指向已经不存在的 `/private/tmp/rtm/ab2/`。归档保存现存链接，无法恢复先前已删除的目标。
- Apple Development 签名身份存在于系统 Keychain，私钥未导出；已保存相关 provisioning profile，但它于 2026-10-15 到期。新机器需要使用 Apple 开发者账号重新配置签名。全局 Keychain、浏览器登录和不相关账号凭据不在此项目备份内。
- AutoDL 归档主要是 2026-10-08 的本机快照，本次没有登录服务器核验今天的远端状态，也没有创建服务器系统镜像。
- 真机备份存在 before-cloud 全量与若干后续样例/云备份；未从当前手机再次导出今天所有新增数据。
- 剪映发现一个未确认相关的其他作品草稿，没有证据表明它是 Shuttl 宣传工程；已确认的 Shuttl 宣传工程为 Python + HTML/Canvas，均纳入。

## 验证标准

1. create 必须没有读取失败或源文件变化，报告 complete=true。
2. verify 必须对清单及全部数据块、全部文件哈希验证通过，然后封存。
3. 在新目录抽样实际恢复源代码、模型、视频、业务数据、历史会话和链接，并验证字节。
4. 每个加密卷都实际解密回读，与封存前哈希比较。
5. 每个 GitHub Release 资产实际下载回读，与本地资产 SHA-256 比较；远端 Git commit 与本地一致。

第 3 项是实际抽样恢复，不是已经在新机器完成全量 App 构建和所有外部服务恢复。最终结果以相应报告为准。
