# 羽析 · 使用说明

羽毛球比赛视频 AI 分析：自动识别每个回合、每一拍的击球方与击球类型、落点界内外（鹰眼回放）、跑动热图，并生成分享图。

## 第一次使用（只做一次）

1. 在"访达"里打开这个文件夹，双击 **安装羽析.command**。
   - 如果提示"无法打开，因为无法验证开发者"：右键点这个文件 → 打开 → 再点"打开"。
   - 如果弹出"安装命令行开发者工具"：点【安装】，装完再双击一次。
2. 等它显示"安装完成"（下载约 300MB，几分钟）。

## 每次使用

1. 双击 **启动羽析.command**，浏览器会自动打开羽析。
2. 手机和电脑连同一个 Wi-Fi，手机浏览器打开终端窗口里显示的地址，就能在手机上用。
3. 用完关掉那个终端窗口即可。

## 拍视频的要求

- 手机横屏，架在底线后方 1–3 米、高 1.5–2 米的位置，固定不动。
- 画面里要能看到球场的四个角。
- 光线充足；一段 1–10 分钟最合适。

## 文件夹结构

```
yuxi/
  安装羽析.command   启动羽析.command
  backend/
    server.py          后端服务 (FastAPI)
    engine/
      tracker.py       羽毛球轨迹追踪 (TrackNetV3 预训练模型, 流式推理)
      court.py         场地标定 (单应性变换) 与界内外判定
      players.py       球员检测 (YOLOX)
      analysis.py      回合切分、击球检测、击球方判定 (HMM)、落点、统计
      pipeline.py      串联以上步骤
    weights/           模型权重
    data/              你上传的视频和分析结果
  frontend/            界面 (index.html / styles.css / court.js / app.js)
```
