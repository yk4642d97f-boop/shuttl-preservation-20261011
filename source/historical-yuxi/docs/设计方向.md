# 羽析 · 设计方向（v3）

> 2026-09-24。放弃 v2 的「iOS App Store 仿制」。用户评价：「拙劣的模仿」「生理不适」。
> 新参考：<https://sleep-well-creatives.com/>（用户指定）。学它的**设计语言与交互结构**，不抄它的品牌。

## 1. 参考站拆解（实测）

Webflow + 自建 Vite 包（`index-8YjIcPvu.js`，1.03 MB）+ Lenis 平滑滚动 + GSAP/ScrollTrigger/SplitText + Three.js r3.13（183 处引用、32 处 `WebGLRenderer`、51 个 `fragmentShader`）+ 12 个 GLB 模型。整页 **41338 px**（1440×900 视口下约 46 屏），6 个编号章节，地面在深蓝 `#0042af` / 近黑 `#010d6e` 与米黄 `#fef1d0` 之间交替。

字体两族：`Editorial`（高对比衬线，700，用于陈述句）+ `NM_Medium/NM_Regular/NM_Light`（Neue Montreal 类无衬线，用于标签正文）。CSS 变量里的间距刻度：`--gap 4/7/13rem`、`--gap-section 7/15/30rem`。

**画面构成**（这是要学的东西）：
1. **双色地面交替**——一整屏深色接着一整屏浅色，每次切换就是一次章节换气。
2. **编辑体大字**——衬线陈述句居中或左对齐，字号远大于正文（约 8×），行高 1.05。
3. **技术底纹**——细到几乎看不见的等高线、点阵、圆弧、十字准星、坐标小字（`THE PULSE WITHIN`、`VIEW 03`）。它不装饰，它提供"这是仪器"的观感。
4. **底部仪表盘**——`THE NOTE`（章节名）· `01 02 03 04 05 06`（章节索引，当前项点亮）· 右侧当前状态。滚动时始终可见，是整页唯一的常驻 UI。
5. **物体摆在空间里**——3D 模型（药瓶、台灯、手、书）不是浮在页面上，而是站在一个透视地面/等高线场上，随滚动被镜头推近、旋转、穿过。
6. **编号叙事**——每个章节有 `01` 序号 + 小标签 + 一句大字 + 两栏小字正文。

## 2. 羽析 v3：把睡眠换成羽毛球

**一句话**：把一场比赛做成一份**可滚动的技术报告**——镜头在球场上方推进，羽毛球按真实轨迹飞出去，每飞一次翻开一个章节。

### 2.1 色彩（借用结构，不借值）

| 角色 | 值 | 用途 |
|---|---|---|
| 墨绿地面 `--ink` | `#08251C` | 深色章节地面（像黑，但在光下认得出是场地色） |
| 骨白地面 `--bone` | `#E9E7E1` | 浅色章节地面（偏冷，避开"米黄+赤陶"的 AI 味） |
| 石墨 `--graphite` | `#0C0C0C` | 浅底正文 |
| 软木黄 `--shuttle` | `#F2C230` | **唯一强调色**：球的轨迹、鹰眼判定、关键数字 |
| 出界红 `--out` | `#E8442E` | 仅语义：出界 / 下网 |
| 场地绿 `--court` | `#1D6B4F` | 球场图形本体（保证一眼认出是球场） |
| 界内白 `--line` | `#FFFFFF` | 边线 |

深色章节用软木黄做强调，浅色章节用墨绿做强调——同一套色在两个地面上都成立。

### 2.2 字体（三个声音，各族分工）

| 角色 | 字体 | 用在哪 | 字号 |
|---|---|---|---|
| 陈述 `--f-display` | Noto Serif SC 700/900（中文）+ Instrument Serif（拉丁/数字） | 章节大字、比分 | `clamp(2.6rem, 6.4vw, 5.6rem)`，行高 1.08，字距 `-0.02em` |
| 仪表 `--f-data` | IBM Plex Mono 500（拉丁数字） | 所有数字、序号、标签、坐标 | 标签 11–12px / `0.14em` 字距 / 大写；大数字 `clamp(3rem, 9vw, 8rem)` |
| 界面 `--f-ui` | Inter 400/500（拉丁）+ Noto Sans SC 400/500（中文） | 按钮、正文、说明 | 15px / 1.65 |

正文 ÷ 大字 ≈ 8×（参考站与获奖站的实测中位数）。所有数字 `font-variant-numeric: tabular-nums`。

### 2.3 核心机制：滚动即飞行

- 报告的骨架是一条**真实回合的轨迹**（`result.json` 的 `trajectory`，逐帧 x/y）。滚动驱动镜头在球场上方推进，球沿线飞出，线本身用 `stroke-dashoffset` 逐段画出（`pattern-recipes` #14）。
- 球落地 → 弹出一个**落点判定**（界内/出界/存疑），这就是章节切换点。下一个章节从落点继续。
- 这条线**不是装饰**：它是这份报告里算法的原始输出。滚回去线会倒着收回去（值每帧写入，不用 CSS 过渡）。
- 静止时也有生命：球持续自转 + 场馆尘埃缓慢上浮（`affordance.md` §11 的"用运动而不是变亮来吸引注意"）。

### 2.4 页面结构（六个章节，对应参考站的 00/06）

| # | 章节 | 地面 | 内容 |
|---|---|---|---|
| 00 | 封面 | 墨绿 | 球场世界 + 羽析字标 + 选择视频；下方折叠区：往期比赛目录 |
| 01 | 概览 | 骨白 | 比分大字 + 回合/拍数/最长/跑动（真实数据） |
| 02 | 落点 | 墨绿 | 俯视球场，落点逐个"盖"上去 + 鹰眼判定 |
| 03 | 回合 | 骨白 | 逐回合：序号 + 拍数 + 击球方色条 + 该回合轨迹缩略 |
| 04 | 双方 | 墨绿 | 击球/失误/球种对比，横向条按真实计数 |
| 05 | 信息 | 骨白 | 技术信息、分享图、重新标定、删除 |

分析中 = 独立一屏（墨绿），把后端真实上报的阶段名做成编号清单 + 巨大的实时百分比 + 飞行进度可视化。

标定 = 精密工具屏（近黑），四角用编号准星 + 发丝线，场线实时叠加；`affordance.md`：标在画出的像素上、按下记录/抬起决定、用 `stroke-dashoffset` 画出"该点这里"。

### 2.5 明确避开（design-slop 闸门）

- 不要居中大标题 + 两颗按钮的默认 hero（A1）→ 封面是满屏场景 + 底部仪表，不是卡片
- 不要三张等权卡片（A2）→ 章节形状各不相同，数字有主次
- 不要每屏同一形状（A3）→ 六种不同骨架
- 不要紫色渐变（A4）；不要发光球/噪点当设计（A5）
- 字号对比 ≥ 4×，目标 8×（A6）
- 不要假手机壳（A7）；不要编造数字（A8）
- 不要每个卡片统一 hover 上浮（B1）；不要全页 fade-up（B2）；缓动分层 ≥3 档 + 弹簧（B3）
- 动效必须来自羽毛球的物理（B5）
- 系统字体栈是"AI 生成页"最大的破绽 → 必须内嵌真实字体

## 3. 实现约束

- **自包含**：全部 canvas 2D + 手写透视投影，不用 three.js/CDN。比赛现场可能没有网络，判卷老师也会读代码；自己写的投影是原创工作量。
- 保留后端与算法不动（v2 已验证）。只重写 `frontend/`。
- 真实数据来源：`result.json`（`trajectory` / `rallies` / `shots` / `landing` / `movement` / `summary`）。
