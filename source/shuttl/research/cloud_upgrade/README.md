# Shuttl 模型升级实验

启动日期：2026-10-07。目标是可验证地改善完整羽毛球分析体验，包括云端推理和真实球馆泛化；不以论文标题、模型大小或训练完成代替效果验证。

所有新实验写到本目录，不覆盖 App 已打包权重。当前没有租赁或购买 GPU。

最新状态见 [租卡前状态](PRE_GPU_READINESS.md)、[云计算接入](CLOUD_INFERENCE.md)。

## 当前进展

- 已实际完成 3 组 HitNet 实验，冻结 40 轮实验的第 30 轮候选。
- 原 5 场测试比赛上，F1@±2 帧从 92.12% 升至 94.55%，首拍检出率从 50.5% 升至 78.9%。
- 额外两场隔离评测也提升；重建特征缓存后计数一致。范围仍限单打的标注回合。
- 已下载并逐项清点 Finebadminton-20K 的 70 份标注和 BFMD 公开子集元数据；二者目前可访问部分都不能补齐双打四人训练。
- 云端视觉模型训练包与采购配置已准备；CUDA 和手机端云服务联调尚未执行。

详细文档：[训练模型卡](MODEL_CARD.md)、[模型与数据调查](MODEL_SURVEY.md)、[两次短租实施单](CLOUD_PLAN.md)。
`cloud/` 为可移植训练入口，`dist/` 为允许列表打包的训练包。

## 评测约束

- 既有测试比赛：039、040、042、043、044。历史工作已多次评测，不能称为全新盲测。
- 新一轮验证：033、041。041 曾被用于调参，033 用来增加验证场景；两者均禁止训练。
- 额外隔离比赛：036、037。现有 HitNet checkpoint 的训练名单未包含它们；本轮仅最终候选确定后打开结果。
- 其他可读的提取比赛用于训练。按整场比赛分组，禁止随机帧拆分造成相邻帧泄漏。
- 当前提取文件来自标注回合，缺少整场休息/捡球等负样本；回合内检测指标不代表完整录像的误报率。
- 已有公开比赛与真实手机球馆录像分开报告；单打结果不能用来声称双打性能。
- 云端 GPU 费用仅做采购建议，由用户购买后再配置。

## 第一组实验

固定旧部署解码器（阈值 0.4，最小间隔 0.30 秒），从 tcn_s0 初始化：

1. 同一新划分上的旧单模型/旧三模型集成基线。
2. 新训练比赛，普通时间窗采样。
3. 同样数据和训练预算，增加首拍附近采样；比较总 F1 和发球召回，检查误报代价。

选择仅用验证集，保留所有失败实验。最终才评测隔离比赛与旧测试集；发布还需要整场视频、真实场地与目标设备/云 GPU 验证。
