# Shuttl 宣传片 · 第二版（promo2）

60 秒，1920×1080，60 fps。纯程序动画：画面（HTML/Canvas，逐帧确定性渲染）和配乐（numpy 合成）都由本目录代码生成，不用任何实拍录像。旧版宣传片在 `../promo/`，未改动。

## 结构与文案

| 时间 | 段落 | 文案 |
|---|---|---|
| 0–6 | 四十分钟录像变成条形码，播放头来回找，锁定一拍后推进 | 那一拍，藏在四十分钟里。 |
| 6–14 | 番茄红上一记扣杀 → 线稿手机录制 → 画面拆成数据块升入云端 GPU | 你只管打。手机只管录。云端，来算。 |
| 14–30 | 一个真实回合按原速重演，分四层"印版"叠加：球 → 球场 → 球员 → 球路；13 次击球就是节奏 | 找到球。一拍一拍，认出来。 |
| 30–40 | App 回合记分卡滚到第 07 分 → 回合详情 → 回放这一分 | 第七分——一点就到。 |
| 40–50 | 击球构成 / 落点地图 / 场上移动，三张结果卡三次硬切 | 看清 · 自己 · 怎么打。 |
| 50–56 | 不确定的一分，长按 0.45 秒 → 改判单 → 判近端得分 → 盖章"已改" | 拿不准的，你来定。 |
| 56–60 | 羽毛球飞入成为标志 | Shuttl. 看清，每一拍。 |

## 数据来源与边界

- 14–30 秒的回合画面由 `prep.py` 从 `research/cloud_upgrade/mobile_sample_20261008/phone-archive.json` 生成：这是 2026-10-08 真机上传、云端 GPU 分析后保存在手机里的输出（逐帧 3D 飞行、击球帧、击球方位置、球路）。只用分析结果，不用原视频画面，片中不出现球员身份。
- 13 次击球里有 2 次球路与人工标注不一致（`phone-accuracy.json`），这两拍在片中不显示球路标签和闪帧。
- 记分卡、回合详情、改判单、统计卡里的回合与数字是示意数据，按 App 现有组件（ShuttlDesign / ShuttlResultsUI）的样式重绘；不代表任何真实比赛成绩。
- 片中不出现：准确率、处理时长、模型名称、"全在手机上算/不联网"、双打、骨架叠加、单独放大的球速。

## 重新生成

```bash
cd promo2
../promo/.venv/bin/python prep.py                 # data.js + 纸张颗粒
../promo/.venv/bin/python stills.py 3 20.5 45     # 抽帧检查（build/stills.jpg）
../promo/.venv/bin/python render.py --audio-only  # 只重做配乐（build/music.wav）
../promo/.venv/bin/python render.py               # 完整渲染 → out/Shuttl-宣传片-2.mp4
```

浏览器预览：打开 `web/index.html?play`（可加 `&t=14` 从某秒开始）。
